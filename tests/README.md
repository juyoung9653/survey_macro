# 테스트 실행

완료·배포 전에 다음 명령을 항상 실행합니다. 실물 PDF 검사도 기본으로 포함하며, 생략된 검사가 있으면 실패로 종료합니다.

```powershell
python -X utf8 run_tests.py
```

검사 범위:

- `scan` 폴더의 모든 PDF 개별 불러오기와 문항 배치
- 같은 양식끼리 2개부터 전체 개수까지 각 묶음 크기의 불러오기와 파일별 칸 연결
- 각 묶음 크기에서 모든 파일을 포함하는 대표 조합(가능한 모든 부분집합을 열거하지는 않음)
- 리더·마음·여행 실제 UI 불러오기 → 기본 프리셋 → 83쪽 분석, 출력 칸 위치와 엑셀 81건 확인
- 자활창업 31쪽 실제 분석과 첫째·둘째·셋째·마지막 페이지의 출력 칸 위치 확인
- 한 장짜리 필기 설문의 답안 보존 및 보드게임 29쪽의 180도 방향 보정
- 나머지 단위·UI·출력 회귀 검사

`python -X utf8 -m unittest discover -s tests -v`로 실행해도 실물 검사는 생략되지 않습니다. 개발 중 특정 테스트만 실행할 수 있지만 전체 검증을 대신하지 않습니다. 모든 필기 답안의 정답 여부까지 검증하는 것은 아닙니다.

기본 자료 위치는 `C:\Users\Public\scan`, 프리셋 위치는 `%LOCALAPPDATA%\CheckFinder\presets`입니다. 각각 `SURVEY_SCAN_CORPUS`, `SURVEY_PRESET_DIR` 환경 변수로 바꿀 수 있습니다. PDF 목록이 바뀌면 새 파일을 검사 대상으로 분류해야 합니다. 자료 누락이나 접근 오류는 실패로 보고하며, 개인 자료는 Git에 포함하지 않습니다.
