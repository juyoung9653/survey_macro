문항과 선택지 설정

자동으로 묶인 문항을 확인하고, 필요한 곳만 다시 묶은 뒤 엑셀에 기록할 이름을 붙입니다.

문항이란?

“서비스에 만족하십니까?”에 매우 만족·만족·보통·불만족 네 칸이 있다면, 네 영역을 하나로 묶은 것이 한 문항입니다.

  • 자동 탐지는 같은 줄의 체크칸을 문항으로 묶어 Q1, Q2처럼 이름을 붙입니다.
  • 초록 박스는 선택형 문항에 들어간 영역입니다.
  • 파란 박스는 직접 추가했지만 아직 문항에 들어가지 않은 영역입니다.

기본 흐름: 확인한 뒤 필요한 곳만 다시 묶기

처음부터 모든 박스를 묶을 필요는 없습니다. 자동으로 만들어진 초록 문항을 위에서 아래로 확인하고, 구성이 맞으면 그대로 다음 단계로 넘어갑니다.

자동 묶기는 위치 기준입니다. 같은 줄의 서로 다른 질문이 하나로 묶였거나, 여러 줄에 걸친 한 질문이 나뉘었다면 그 칸들을 선택해 올바른 문항으로 다시 묶으세요.

여러 박스 선택하기

  • 클릭: 박스 한 개를 선택합니다.
  • Ctrl + 클릭: 떨어진 박스를 하나씩 추가하거나 선택 해제합니다.
  • Shift + 클릭: 마지막 기준 박스부터 클릭한 박스까지 한꺼번에 선택합니다. 같은 줄이면 가로, 같은 열이면 세로, 대각선 위치면 두 박스를 모서리로 하는 사각 범위가 선택됩니다.
  • 빈 공간 드래그: 붉은 점선 안에 걸친 박스를 선택합니다. 기존 선택에 더하려면 Ctrl을 누른 채 드래그합니다.
엑셀 셀을 고르는 방식과 비슷합니다.
연속된 선택지는 Shift, 서로 떨어진 선택지는 Ctrl을 사용하면 빠릅니다.

잘못 묶인 문항 다시 만들기

  1. 같은 질문에 속한 영역을 클릭·Ctrl·Shift 또는 드래그로 모두 선택합니다.
  2. 문항으로 묶기를 누릅니다.
  3. 결과에서 알아보기 쉬운 문항 이름을 입력합니다. 예: 서비스 만족도
  4. 확인을 누르고 초록 박스 옆 이름이 맞는지 확인합니다.
기존 문항에서 다시 묶어도 괜찮습니다.
선택한 영역만 새 문항으로 이동하며, 기존에 입력한 선택지 이름은 가능한 범위에서 함께 보존됩니다.

선택지는 페이지 순서 → 위에서 아래 → 같은 줄의 왼쪽에서 오른쪽 순으로 정리됩니다.

먼저 평균을 낼 문항인지 확인하기

  1. 선택지 이름 설정을 누릅니다.
  2. 문항 선택에서 수정할 문항을 고릅니다.
  3. 문항 이름을 실제 질문에 맞게 바꿉니다.
  4. 평균용 문항은 오른쪽 선택지 이름을 모두 비워 두고 평균 보기를 체크합니다. ‘매우 불만족’이나 숫자를 다시 입력하지 마세요. 왼쪽 번호가 점수입니다.
  5. 평균 없이 이름을 표시할 문항만 오른쪽 칸에 결과값을 입력합니다. 예: 인터넷, 지인 소개, 홍보물.
  6. 다른 문항도 차례로 확인하고 확인을 누릅니다.
설문지 위치선택지 이름 예엑셀 결과
이용 경로 첫 번째 칸인터넷인터넷
이용 경로 두 번째 칸지인 소개지인 소개
이용 경로 세 번째 칸홍보물홍보물
이름을 비워 둔 칸빈 칸해당 번호
문항 이름은 반드시 서로 달라야 합니다.
같은 이름(대소문자만 다른 경우 포함), 빈 이름, 결과 열 이름인 파일명·페이지는 적용되지 않습니다. 이는 엑셀 열이 조용히 덮어써지는 일을 막기 위한 안전장치입니다.

설정 창의 추가 기능

선택지 번호 방향 (문항별)

번호 역순을 바꾸면 이미 입력한 선택지 이름도 자동 재배치됩니다. 각 체크칸에 대응하는 이름은 유지되므로 다시 입력하지 않아도 됩니다. 이름이 비어 있는 평균용 문항은 번호 점수만 바뀝니다.

문항 선택 → 선택지 번호 방향에서 정순/역순을 고르고 아래 점수 순서를 확인하세요. 선택한 문항만 바뀌며, 다른 문항의 방향은 그대로입니다.

  • 매우 불만족 → 매우 만족 순서라면 정순: 1 → 5점
  • 매우 만족 → 매우 불만족 순서라면 역순: 5 → 1점

위 예시는 매우 만족을 5점으로 처리할 때의 기준입니다. 부정형 질문을 자동으로 판별하는 역채점 기능이나 PDF 회전 기능은 아닙니다. 기존 프리셋은 예전 전체 방향을 이어받고, 수정 후 확인·저장하면 문항별 방향이 함께 저장됩니다.

중복 허용

“해당하는 항목을 모두 선택”처럼 여러 칸을 고를 수 있는 질문만 중복 허용을 켭니다. 결과는 쉼표로 이어서 기록됩니다.

평균 보기

점수형 문항은 선택지 이름을 모두 비우고 평균 보기를 체크합니다. 왼쪽 번호를 점수로 사용하므로 점수 방향도 확인하세요. 문항 이름 변경은 괜찮지만, 선택지 이름에 글자나 숫자를 입력하면 평균 보기가 자동 해제됩니다. 이미 입력했다면 오른쪽 값을 전부 지우고 평균 보기를 다시 체크하세요.

일괄 적용

선택지 개수가 같은 문항들에 현재 선택지 이름·번호 방향·중복 허용·평균 보기 설정을 함께 복사합니다. 문항 이름은 복사하지 않습니다. 같은 보기 순서의 5점 척도가 반복될 때 유용합니다.

일괄 적용 뒤에도 한두 문항은 직접 확인하세요.
선택지 개수는 같지만 뜻이나 순서가 다른 문항까지 선택하지 않도록 주의합니다.

분석 전 문항 점검

  • 문항 이름이 서로 겹치지 않고 알아보기 쉬운가
  • 각 문항의 박스 개수가 실제 선택지 개수와 같은가
  • 선택지 이름과 번호 방향이 실제 설문 순서와 같은가
  • 복수 응답 문항에만 중복 허용이 켜졌는가
  • 필요한 점수형 문항에만 평균 보기가 켜졌는가
