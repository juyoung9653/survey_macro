문항과 선택지 설정

같은 질문의 체크칸을 하나의 문항으로 묶고, 엑셀에 기록할 이름을 붙입니다.

문항이란?

“서비스에 만족하십니까?”에 매우 만족·만족·보통·불만족 네 칸이 있다면, 네 영역을 하나로 묶은 것이 한 문항입니다.

  • 자동 탐지가 만든 문항은 Q1, Q2처럼 이름이 붙습니다.
  • 초록 박스는 선택형 문항에 들어간 영역입니다.
  • 파란 박스는 아직 문항에 들어가지 않은 영역입니다.

여러 박스 선택하기

  • 클릭: 박스 한 개를 선택합니다.
  • Ctrl + 클릭: 떨어진 박스를 하나씩 추가하거나 선택 해제합니다.
  • Shift + 클릭: 마지막 기준 박스부터 클릭한 박스까지 한꺼번에 선택합니다. 같은 줄이면 가로, 같은 열이면 세로, 대각선 위치면 두 박스를 모서리로 하는 사각 범위가 선택됩니다.
  • 빈 공간 드래그: 붉은 점선 안에 걸친 박스를 선택합니다. 기존 선택에 더하려면 Ctrl을 누른 채 드래그합니다.
엑셀 셀을 고르는 방식과 비슷합니다.
연속된 선택지는 Shift, 서로 떨어진 선택지는 Ctrl을 사용하면 빠릅니다.

잘못 묶인 문항 다시 만들기

  1. 같은 질문에 속한 영역을 클릭·Ctrl·Shift 또는 드래그로 모두 선택합니다.
  2. 문항으로 묶기를 누릅니다.
  3. 결과에서 알아보기 쉬운 문항 이름을 입력합니다. 예: 서비스 만족도
  4. 확인을 누르고 초록 박스 옆 이름이 맞는지 확인합니다.
기존 문항에서 다시 묶어도 괜찮습니다.
선택한 영역만 새 문항으로 이동하며, 기존에 입력한 선택지 이름은 가능한 범위에서 함께 보존됩니다.

선택지는 페이지 순서 → 위에서 아래 → 같은 줄의 왼쪽에서 오른쪽 순으로 정리됩니다.

선택지 이름 붙이기

  1. 선택지 이름 설정을 누릅니다.
  2. 문항 선택에서 수정할 문항을 고릅니다.
  3. 문항 이름을 실제 질문에 맞게 바꿉니다.
  4. 표의 선택지 이름에 결과값을 입력합니다. 예: 매우 만족, 만족, 보통, 불만족
  5. 다른 문항도 차례로 확인하고 확인을 누릅니다.

문항 이름은 반드시 서로 달라야 합니다.
같은 이름(대소문자만 다른 경우 포함), 빈 이름, 결과 열 이름인 파일명·페이지는 적용되지 않습니다. 이는 엑셀 열이 조용히 덮어써지는 일을 막기 위한 안전장치입니다.

설정 창의 추가 기능

번호 역순

상단 표시가 현재 번호 역순: ON이면 박스 번호가 반대 방향으로 매겨집니다. 설문지의 첫 선택지와 설정 창의 번호가 맞지 않으면 파일 → 페이지 설정 → 번호 역순을 바꾸고 다시 확인하세요.

중복 허용

“해당하는 항목을 모두 선택”처럼 여러 칸을 고를 수 있는 질문만 중복 허용을 켭니다. 결과는 쉼표로 이어서 기록됩니다.

평균 보기

점수형 문항의 평균을 별도 시트로 만들 때 켭니다. 선택지 위치를 1, 2, 3… 점수로 사용합니다. 선택지 이름을 처음 입력할 때 자동으로 꺼질 수 있으므로 마지막에 원하는 상태를 확인하세요.

일괄 적용

선택지 개수가 같은 문항들에 현재 선택지 이름·중복 허용·평균 보기 설정을 복사합니다. 같은 5점 척도가 반복될 때 유용합니다.

일괄 적용 뒤에도 한두 문항은 직접 확인하세요.
선택지 개수는 같지만 뜻이나 순서가 다른 문항까지 선택하지 않도록 주의합니다.

분석 전 문항 점검

  • 문항 이름이 서로 겹치지 않고 알아보기 쉬운가
  • 각 문항의 박스 개수가 실제 선택지 개수와 같은가
  • 선택지 이름과 번호 방향이 실제 설문 순서와 같은가
  • 복수 응답 문항에만 중복 허용이 켜졌는가
  • 필요한 점수형 문항에만 평균 보기가 켜졌는가
