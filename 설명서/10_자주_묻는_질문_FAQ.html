문제 해결

증상에 맞는 항목을 열고 위에서부터 확인하세요.

PDF와 화면

PDF를 골랐는데 화면이 바뀌지 않아요
파일 선택 뒤 나오는 페이지 수 창에서 확인을 눌렀는지 봅니다. 취소했다면 기존 문서는 그대로 유지됩니다. 다시 PDF 불러오기를 누르세요.
PDF 불러오기 오류가 나면 이전 작업도 사라지나요?
아니요. 파일 읽기·템플릿 생성·자동 탐지 중 문제가 생기면 이전 PDF, 문항, 프리셋 상태로 되돌아갑니다. 오류 창의 세부 내용을 확인하고 손상 또는 암호 설정 여부를 점검하세요.
두 번째 응답부터 페이지가 서로 섞여요
한 부당 페이지 수를 잘못 입력했을 가능성이 큽니다. 예를 들어 2쪽 설문 28부가 들어 있는 56페이지 PDF는 2를 입력해야 합니다. PDF를 다시 불러오세요.
페이지가 옆으로 누웠거나 조금 기울었어요
90도 회전은 파일 → 페이지 설정 → 회전, 작은 기울기는 자동 수평 맞춤, 마지막 미세 조정은 전체 미세 회전을 사용합니다.

박스 편집

체크박스를 너무 많이 또는 너무 적게 찾았어요
빠진 칸은 선택지 추가로 그리고, 잘못 잡은 칸은 선택·이동에서 클릭한 뒤 Delete로 지웁니다. 스캔 파일을 같은 이름으로 교체한 뒤 이전 탐지가 반복된다면 파일 → 캐시 삭제로 다시 탐지하세요.
클릭해도 선택되지 않고 계속 박스만 그려져요
Esc를 누르거나 선택·이동 버튼을 누릅니다. 회색 안내 줄이 “선택·이동”으로 시작하는지 확인하세요.
여러 박스를 빠르게 선택하고 싶어요
떨어진 박스는 Ctrl + 클릭으로 하나씩 추가·해제합니다. 연속된 박스는 첫 박스를 클릭한 뒤 마지막 박스를 Shift + 클릭합니다. 가로·세로뿐 아니라 대각선으로 클릭하면 두 박스 사이의 사각 범위가 선택됩니다.
박스 크기를 바꾸고 싶어요
박스를 한 개만 선택한 뒤 노란색 모서리를 드래그합니다. 여러 개가 선택된 상태에서는 크기 조절점이 나타나지 않습니다.
실수로 지웠어요
Ctrl + Z를 누릅니다. 다시 적용하려면 Ctrl + Y를 누릅니다.

문항과 프리셋

선택지 이름과 실제 위치가 반대로 나와요
파일 → 페이지 설정 → 번호 역순 상태를 바꾸고 선택지 이름 설정을 다시 엽니다. 첫 체크칸의 번호와 이름이 실제 설문 순서와 같은지 확인하세요.
프리셋을 불러왔는데 위치가 안 바뀐 것 같아요
정상일 수 있습니다. 가까운 자동 탐지 박스는 현재 위치를 유지하고 프리셋의 문항 이름과 선택지 값만 적용합니다. 박스가 실제 체크칸을 감싸고 값 순서가 맞는지 확인하세요.
“현재 PDF와 일치하지 않는 프리셋”이라고 나와요
다른 설문 양식, 잘못된 페이지 수, 페이지 순서 변경, 큰 잘림이나 회전을 확인합니다. 실패한 프리셋은 적용되지 않으므로 맞는 프리셋을 고르거나 새 설정을 만드세요.
새 PDF를 열었더니 프리셋이 미적용으로 바뀌었어요
의도된 안전 동작입니다. 새 PDF의 자동 탐지 결과가 기존 프리셋에 덮어써지는 일을 막습니다. PDF를 연 다음 같은 양식의 프리셋을 다시 불러오세요.
문항 이름이 중복됐다는 경고가 나와요
엑셀에서 각 문항이 별도 열로 보존되도록 문항마다 다른 이름을 입력합니다. 대소문자만 다른 이름도 중복으로 처리하며 파일명, 페이지는 사용할 수 없습니다.

분석과 결과

분석 실행 버튼을 눌러도 시작되지 않아요
PDF가 불러와져 있고 문항이 하나 이상 있는지 확인합니다. 영역이 모두 삭제되었다면 PDF를 다시 불러오거나 선택지를 추가해 문항으로 묶습니다.
분석이 오래 걸려요
고해상도·다페이지 PDF는 시간이 걸립니다. 진행률과 현재 파일 메시지가 바뀌면 기다립니다. 다른 무거운 프로그램을 닫으면 메모리 부족 가능성을 줄일 수 있습니다.
결과 파일을 찾을 수 없어요
화면의 결과 폴더 버튼을 누릅니다. 파일 이름에는 실행한 연도·월·일·시·분·초가 붙습니다. 완료가 아니라 오류 창이 나왔다면 가장 최근 검토용 결과가 부분 결과인지 확인합니다.
자유기입 PDF가 없어요
자유기입 영역이 없거나 의미 있는 필기가 감지되지 않으면 만들지 않습니다. 엑셀 결과에서 해당 자유기입 열이 모두 비어 있는지 확인하세요.
엑셀에 검수필요가 나왔어요
오류로 단정하지 않고 사람이 판단하도록 남긴 항목입니다. 검수필요 시트의 원본 이미지와 후보를 보고, 결과 시트의 값을 맞는 선택지로 수정하세요.

프로그램 실행

더블클릭해도 프로그램이 열리지 않아요
설문지스캔.exe가 있으면 먼저 사용합니다. 소스 실행이라면 Python 연결과 인터넷 상태를 확인합니다. 이거_더블클릭해서_실행.py를 실행할 때 터미널에 설치 실패 메시지가 보이면 그 내용을 관리자에게 전달하세요.
문제가 반복될 때 무엇을 전달해야 하나요?
사용한 PDF 이름, 한 부당 페이지 수, 프리셋 이름, 오류 창 문구, 가장 최근 결과 폴더를 함께 전달하면 원인을 찾기 쉽습니다. 개인정보가 있는 원본 PDF는 승인된 담당자에게만 전달하세요.
