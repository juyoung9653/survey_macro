실행과 PDF 준비

프로그램을 여는 방법과, 자동 인식이 잘 되는 PDF의 조건을 정리합니다.

프로그램 실행

실행 파일이 있는 경우 설문지스캔.exe를 더블클릭합니다. Python 설치 없이 실행하는 배포 방식입니다.
소스 폴더인 경우 이거_더블클릭해서_실행.py를 더블클릭합니다. Python이 필요합니다.

소스 실행은 필요한 구성 요소가 없으면 자동 설치합니다. 첫 실행만 인터넷 연결과 시간이 필요할 수 있습니다.

검은 터미널 창이 함께 열렸다면 그대로 두세요.
소스 실행 중 그 창을 닫으면 프로그램도 종료될 수 있습니다. 프로그램 창의 X 버튼으로 정상 종료하세요.

PDF 준비 기준

확인할 것권장 상태이유
설문 양식한 번에 고른 파일이 모두 동일저장된 문항과 영역 위치를 공통으로 사용합니다.
해상도글자와 체크 선이 선명한 300 DPI 안팎너무 흐리거나 압축이 심하면 테두리와 필기 구분이 어려워집니다.
페이지 순서각 설문이 같은 순서로 반복예: 2쪽짜리는 1쪽·2쪽, 다음 응답의 1쪽·2쪽 순서여야 합니다.
방향가능하면 모두 같은 회전 방향서로 뒤집힌 페이지가 섞이면 별도 보정이 필요합니다.
여백체크칸이 잘리지 않음페이지 가장자리에서 잘린 칸은 자동 탐지하기 어렵습니다.

“한 부당 페이지 수”란?

한 사람이 작성한 설문 한 묶음에 들어가는 페이지 수입니다. PDF 파일 수와는 다릅니다.

  • 한 사람이 한 페이지만 작성: 1
  • 앞면과 뒷면 두 페이지를 작성: 2
  • 세 페이지짜리 설문: 3
한 PDF 안에 여러 사람의 설문이 이어져 있어도 됩니다.
예를 들어 2쪽짜리 응답 28부가 한 PDF에 있으면 총 56페이지이며, 입력값은 2입니다.
페이지 수를 잘못 입력하면 응답끼리 섞입니다.
분석 전에 첫 응답과 다음 응답의 시작 페이지가 맞는지 확인하세요.

기울거나 돌아간 스캔

PDF를 불러올 때 페이지 종류별 작은 기울기는 자동으로 맞춥니다.

  • 자동 보정 뒤에도 기울어 보이는 경우: 상단 기울기 다시 맞추기를 사용합니다.
  • 전체가 90도 돌아간 경우: 파일 → 페이지 설정 → 회전에서 방향을 고릅니다.
  • 아주 드문 경우에 직접 각도를 지정할 때: 파일 → 기울기 → 수동 기울기 조정을 사용합니다.

회전이나 기울기 설정을 바꾸면 체크박스를 다시 탐지하므로 잠시 기다릴 수 있습니다.
