처음 분석하기

처음 실행한 사람이 PDF를 불러와 결과 파일을 확인할 때까지의 가장 짧은 순서입니다.

시작 전에 준비할 것

  • 같은 설문 양식으로 스캔한 PDF
  • 설문지 한 부의 페이지 수: 한 장이면 1, 앞·뒤 두 쪽이면 2
  • 각 선택지가 엑셀에 어떻게 표시될지 정한 이름
서로 다른 설문 양식은 한 번에 섞지 마세요.
문항과 체크박스 위치가 같은 PDF끼리 한 번씩 분석하는 것이 안전합니다.

한 번 끝까지 따라하기

  1. 프로그램을 실행합니다.
    설문지스캔.exe가 있으면 더블클릭합니다. 소스 폴더에서는 이거_더블클릭해서_실행.py를 사용합니다.
  2. PDF 불러오기를 누릅니다.
    같은 양식의 PDF를 모두 선택하고, “설문지 한 부는 몇 페이지인가요?”에 맞는 숫자를 입력합니다.
  3. 자동으로 찾고 묶은 문항을 확인합니다.
    체크칸은 줄마다 Q1, Q2처럼 자동으로 묶여 초록 박스로 보입니다. 실제 체크칸과 문항 구성이 맞는지 확인하고, 틀린 곳만 다시 묶습니다.
  4. 저장한 프리셋이 있다면 지금 불러옵니다.
    프리셋 불러오기를 누르고 이름을 선택합니다. 처음 만드는 양식이면 이 단계는 건너뜁니다.
  5. 문항과 선택지 이름을 확인합니다.
    잘못 묶인 영역을 선택해 문항으로 묶기를 누릅니다. 이어서 선택지 이름 설정에서 문항명과 선택지 이름을 입력합니다.
  6. 글이나 숫자를 쓰는 칸이 있으면 자유기입 영역으로 지정합니다.
    자유기입 영역 추가를 누르고 답변 칸을 드래그합니다.
  7. ▶ 분석 실행을 누릅니다.
    진행 창이 끝날 때까지 기다립니다. 분석 중에는 프로그램을 닫지 않습니다.
  8. 결과 폴더를 누릅니다.
    가장 최근 시각이 붙은 결과 폴더를 열어 엑셀과 검토용 PDF를 확인합니다.

완료 확인

결과/ └─ 설문결과_연도.월.일.시.분.초/ ├─ 설문결과.xlsx ├─ 자유기입.pdf (내용이 있을 때) └─ 검토용/ ├─ 00_추론된_템플릿.pdf ├─ 파일명_원본포함.pdf └─ 파일명_잉크추출.pdf
  • 엑셀 결과 시트에서 응답이 맞는지 몇 줄 확인
  • 검수필요 시트가 있으면 표시된 행과 원본 이미지 확인
  • _원본포함.pdf에서 영역 위치가 어긋나지 않았는지 확인
여기까지 되면 첫 분석이 끝난 것입니다.
같은 양식은 프리셋으로 저장해 두면 다음부터 설정 시간을 줄일 수 있습니다.
