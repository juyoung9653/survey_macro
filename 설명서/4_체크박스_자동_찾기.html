영역 추가·선택·이동·삭제

평소에는 박스를 바로 클릭해 편집하고, 새 영역을 그릴 때만 추가 도구를 누릅니다. 현재 동작은 회색 안내 줄에서 확인할 수 있습니다.

기본 선택과 두 가지 추가 도구

기본 선택 상태별도 버튼 없이 박스를 클릭해 선택하고 이동·크기 조절·삭제합니다.
선택지 추가자동 탐지에서 빠진 체크칸을 드래그합니다. 하나를 그리면 기본 선택 상태로 돌아갑니다.
자유기입 영역 추가글이나 숫자를 적는 답변 칸을 드래그합니다. 한 번 그리면 선택 모드로 돌아옵니다.
Esc그리던 작업을 취소하고 기본 선택 상태로 돌아갑니다.

빠진 선택지 추가

  1. 선택지 추가를 누릅니다. 마우스 커서가 십자 모양으로 바뀝니다.
  2. 체크칸의 왼쪽 위에서 오른쪽 아래까지 드래그합니다.
  3. 생긴 파란 박스가 체크칸 테두리를 감싸는지 봅니다.
  4. 하나를 그리면 자동으로 선택 상태로 돌아갑니다. 다른 칸도 추가하려면 선택지 추가를 다시 누릅니다.
페이지 경계를 가로질러 그리지 마세요.
영역은 시작한 페이지 안으로 제한됩니다. 페이지마다 따로 그리면 정확합니다.

노란 굵은선이 현재 선택된 영역입니다. 이후 이동·삭제·문항 묶기는 이 영역에 적용됩니다.

이동과 크기 조절

이동

  • 선택한 박스 안쪽을 드래그하면 이동합니다.
  • 여러 개를 선택하면 함께 움직입니다.
  • 정밀 이동은 작업 화면을 한 번 클릭한 뒤 방향키를 누릅니다.
  • Shift + 방향키는 한 번에 10픽셀씩 움직입니다.

크기 조절

  • 박스를 한 개만 선택합니다.
  • 노란색 모서리 점을 드래그합니다.
  • 박스는 페이지 밖으로 나가지 않으며 너무 작아지지 않도록 제한됩니다.
확대하고 조절하면 쉽습니다.
Ctrl + 마우스 휠로 체크칸을 크게 본 뒤 모서리를 맞추세요.

삭제와 되돌리기

  • 선택 후 선택 삭제, Delete 또는 Backspace
  • 박스를 우클릭하면 선택 영역 삭제, 새 문항으로 묶기, 문항 전체 삭제 메뉴를 사용할 수 있습니다.
  • 여러 개 또는 문항 전체를 지울 때는 확인 창이 나타납니다.
  • Ctrl + Z: 실행 취소
  • Ctrl + Y: 다시 실행
삭제 확인 창이 떠도 되돌릴 수 있습니다.
실수했다면 바로 Ctrl + Z를 누르세요. 최근 편집 50개까지 기록됩니다.
