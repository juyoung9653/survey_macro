분석 실행과 결과 확인

설정을 마지막으로 점검하고, 엑셀의 원본 결과와 자동 검수 대상을 확인합니다.

분석 전 30초 점검

  • 같은 양식의 PDF만 불러왔는가
  • 한 부당 페이지 수가 맞는가
  • 모든 선택형 박스가 실제 체크칸을 감싸는가
  • 문항 이름과 선택지 순서가 맞는가
  • 자유기입 영역이 답변 칸 전체를 포함하는가

분석 실행

  1. 오른쪽 위 ▶ 분석 실행을 누릅니다.
  2. 진행 창에서 현재 파일, 단계, 진행률, 경과 시간과 예상 시간을 확인합니다.
  3. 완료 안내가 나올 때까지 기다립니다. 분석 중에는 실행 버튼이 잠기며 프로그램을 종료할 수 없습니다.
  4. 완료 창에서 총 소요 시간과 저장 위치 안내를 확인한 뒤 결과 폴더를 누릅니다.
분석 시간은 고정되어 있지 않습니다.
PDF 페이지 수, 해상도, 컴퓨터 메모리와 CPU에 따라 달라집니다. 진행 메시지가 바뀌고 있다면 정상 처리 중입니다.

결과 저장 위치

실행 파일 또는 실행용 Python 파일이 있는 폴더 옆의 결과 폴더에, 실행 시각이 붙은 새 결과가 만들어집니다.

결과/ ├─ 설문결과_2026.08.27.14.30.15.xlsx ├─ 설문결과_2026.08.27.14.30.15_자유기입.pdf └─ 설문결과_2026.08.27.14.30.15_검토용/ ├─ 00_추론된_템플릿.pdf ├─ 급식_원본포함.pdf ├─ 급식_잉크추출.pdf └─ ...

파일명은 초 단위까지 구분됩니다. 같은 초에 다시 실행해도 _2, _3이 붙어 기존 결과를 덮어쓰지 않습니다. 자유기입 PDF는 필기가 감지된 경우에만 생성됩니다.

엑셀 시트 읽는 법

시트내용먼저 볼 때
결과응답이 하나 이상 감지된 설문 한 부당 한 줄. 파일명, 페이지, 각 문항의 판독 결과전체 원자료를 확인하거나 수정할 때
검수필요두 선택지가 모두 뚜렷한 등 자동 확정이 위험한 문항과 원본 이미지시트가 생성되어 있다면 가장 먼저
전체 통계문항별 선택 개수, 응답률, 미응답전체 설문 요약을 볼 때
평균평균 보기를 켠 문항의 전체·파일별 위치 점수 평균점수형 문항을 비교할 때
파일명 시트각 PDF 파일에 들어 있는 응답만 따로 계산한 통계기관·장소별 PDF를 비교할 때

모든 선택형·자유기입 항목이 완전히 빈 설문은 결과 행에서 제외됩니다.

검수필요는 오류 확정이 아니라 “사람이 결정할 항목”입니다.
결과 시트에는 검수필요(후보1/후보2)처럼 표시됩니다. 검수필요 시트의 원본 이미지를 보고 맞는 값으로 고치세요.

검토용 PDF 확인 순서

  1. 파일명_원본포함.pdf를 열어 번호 박스가 실제 체크칸 위에 있는지 봅니다.
  2. 파일명_잉크추출.pdf에서 실제 체크나 취소 표시가 남았는지 봅니다.
  3. 문제가 있는 설문은 엑셀 결과 시트의 파일명과 페이지 열로 찾습니다.

00_추론된_템플릿.pdf는 여러 응답에서 만든 빈 양식 기준입니다. 특정 파일 전체가 어긋난다면 이 기준과 스캔 형태가 크게 다른지 확인하세요.
