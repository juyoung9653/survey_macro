프리셋 저장과 불러오기

같은 설문 양식의 문항·선택지·영역 위치를 다시 만들지 않도록 저장합니다.

언제 사용하나요?

  • 매달 또는 매년 같은 설문지를 분석할 때
  • 여러 기관에서 같은 인쇄 양식을 사용했을 때
  • 한 번 검수한 문항 이름과 선택지 순서를 그대로 쓰고 싶을 때
문항이나 체크칸 위치가 다른 양식에는 같은 프리셋을 쓰지 마세요.
프로그램은 분명히 다른 양식이면 적용을 거부하지만, 최종 확인은 사용자가 해야 합니다.

프리셋 저장

  1. PDF를 불러오고 영역·문항·선택지·자유기입 설정을 모두 마칩니다.
  2. 처음 저장할 때는 상단 프리셋 저장을 누릅니다. 다른 사본을 만들려면 파일 → 프리셋 → 다른 이름으로 저장을 사용합니다.
  3. 설문 종류가 드러나는 이름을 입력합니다. 예: 급식 만족도 2026
  4. 상단 상태에 프리셋: 저장한 이름이 표시되는지 확인합니다.

편집 뒤에는 상단 상태에 (수정됨)이 붙고 저장하면 사라집니다. 파일 → 프리셋 → 저장은 현재 이름의 프리셋을 갱신합니다. 다른 이름으로 저장에서 이미 있는 이름을 고르면 덮어쓰기 전에 한 번 더 확인합니다.

프리셋 불러오기: 순서가 중요합니다

  1. 먼저 PDF 불러오기로 이번에 분석할 PDF를 엽니다.
  2. 자동 탐지가 끝난 뒤 프리셋 불러오기를 누릅니다.
  3. 같은 설문 양식의 프리셋 이름을 선택합니다.
  4. 정렬 진행이 끝나면 문항 이름, 선택지 순서, 자유기입 영역을 확인합니다.
  5. 상단 상태에 적용한 프리셋 이름이 표시되는지 확인합니다.
새 PDF를 열면 프리셋 상태는 “미적용”으로 초기화됩니다.
이전 프리셋 이름이 남아 잘못 덮어쓰는 일을 막기 위한 동작입니다.
저장하지 않은 편집은 조용히 사라지지 않습니다.
다른 PDF나 프리셋으로 이동하거나 프로그램을 닫을 때 저장, 저장하지 않음, 취소 중에서 선택할 수 있습니다.

불러오면 박스 위치가 바뀌나요?

현재 PDF에서 자동으로 찾은 체크박스 위치를 우선 유지합니다. 가까운 프리셋 박스가 확인되면 좌표를 억지로 옮기지 않고 문항 이름·선택지 값·분석 설정만 입힙니다.

  • 서로 맞는 체크박스는 이번 자동 탐지 위치를 그대로 사용합니다.
  • 자유기입 영역과 직접 그린 박스는 확인된 전체 이동량에 맞춰 함께 옮깁니다.
  • 프리셋과 짝이 없는 기존 자동 탐지 박스는 남기지 않습니다.
  • 실제 분석에서는 각 응답의 체크박스 근처를 다시 찾아 작은 위치 차이를 보정합니다.
  • 체크박스 탐지가 불완전하면 저장된 템플릿 정렬로 안전하게 되돌아갑니다.
프리셋은 “무슨 문항인지”, 자동 탐지는 “이번 PDF에서 어디에 있는지”를 맡습니다.
가까운 박스의 위치만 재사용하므로 프리셋을 불러온 뒤에는 프리셋에 포함된 문항과 영역만 화면에 남습니다.

프리셋 적용이 거부될 때

현재 PDF와 일치하지 않는 프리셋이라 불러올 수 없습니다.가 나오면 다음을 확인합니다.

  1. 프리셋 이름을 잘못 선택하지 않았는지
  2. 한 부당 페이지 수와 페이지 순서가 같은지
  3. 인쇄 양식이 개정되어 체크칸이 옮겨지지 않았는지
  4. 스캔이 잘리거나 90도 돌아가지 않았는지

적용 실패 시 기존 편집 상태는 복구됩니다. 다른 프리셋을 고르거나 새 양식으로 다시 설정하세요.

프리셋 삭제

파일 → 프리셋 → 삭제에서 이름을 선택합니다. 삭제한 설정은 일반 실행 취소로 복구되지 않으므로 설문 양식을 더 이상 쓰지 않을 때만 삭제하세요.
