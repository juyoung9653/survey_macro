화면 구성과 PDF 불러오기

화면은 “문서 작업”, “영역 편집”, “현재 안내”, “설문지 화면” 순으로 나뉩니다.

화면 부분하는 일
첫째 줄PDF와 프리셋을 불러오거나 저장하고, 페이지를 보정합니다. 오른쪽은 실행 취소 → 다시 실행 → 분석 실행 → 결과 폴더 순서입니다.
둘째 줄선택지·자유기입 영역을 고치고, ‘설명서’나 항목 도움말을 엽니다.
위쪽 도움말 버튼‘설명서’ 옆의 ‘? 항목 도움말’을 누르면 사용법 안내 후 궁금한 항목을 클릭해 설명을 볼 수 있습니다. 안내에서 ‘다시 보지 않기’를 체크하면 다음부터 안내창은 생략됩니다. 항목을 우클릭해도 도움말을 볼 수 있으며, Esc로 도움말 모드를 끝냅니다.
안내 줄현재 선택한 도구와 다음에 할 동작을 알려줍니다.
큰 작업 화면설문지 이미지, 문항 이름, 영역 색상을 보여줍니다.

PDF 불러오기

  1. PDF 불러오기를 누릅니다.
  2. 같은 설문 양식의 파일을 선택합니다. 여러 파일은 Ctrl을 누른 채 클릭하거나 파일 선택 창에서 범위 선택합니다.
  3. “설문지 한 부는 몇 페이지인가요?”에 1~10 사이의 값을 입력합니다.
  4. PDF 로딩, 기울기 보정, 빈 양식 생성, 체크박스 탐지와 문항 자동 묶기가 끝날 때까지 기다립니다.
  5. 상단 상태가 PDF n개 · n쪽/부 · 프리셋: 미적용 · 화면: 자동 생성 빈 양식처럼 바뀌었는지 확인합니다.
여러 파일을 선택하면 첫 파일이 문항 설정 화면의 기준입니다.
문항 순서와 선택지 개수가 같은 파일은 칸의 위치나 너비가 조금 달라도 함께 처리할 수 있습니다. 분석할 때 각 PDF의 양식을 따로 만들고, 각 페이지의 실제 칸 위치에 맞춥니다. 교육명이 달라도 함께 선택할 수 있지만, 문항 구성이 다르면 따로 처리해주세요.
새 PDF를 열면 이전 프리셋은 자동으로 해제됩니다.
상태에 프리셋: 미적용이 표시되므로, 같은 양식의 저장 설정을 쓰려면 PDF를 연 다음 프리셋을 다시 불러오세요.
편집한 내용이 있으면 먼저 저장 여부를 묻습니다.
PDF를 읽지 못하거나 중간 단계에서 오류가 나면 새 파일을 일부만 적용하지 않고, 이전 문서와 프리셋 화면으로 되돌아갑니다.

화면 보기와 확대

  • Ctrl + 마우스 휠: 커서 위치를 중심으로 확대·축소
  • 마우스 휠 또는 스크롤바: 긴 페이지 이동
  • 파일 → 페이지 설정 → 모아보기/세로 보기: 여러 페이지 배치 전환

가로로 긴 페이지는 두 페이지 나란히 보기가 제한될 수 있습니다. 이 경우 세로로 이어진 화면을 사용하세요.

자동 탐지 후 먼저 볼 것

작업 화면에는 응답 표시를 줄여 만든 빈 양식 기준이 표시됩니다. 화면을 보기 쉽게 하기 위한 기준이며, 분석할 때는 각 PDF의 실제 응답 페이지를 따로 처리합니다.

  • 실제 체크칸마다 초록색 박스가 있는가
  • 체크칸이 아닌 표 테두리나 글자에 불필요한 박스가 없는가
  • 같은 질문의 선택지들이 Q1, Q2처럼 한 문항으로 묶였는가
  • 2쪽 이상이면 각 페이지의 위치가 모두 맞는가
상단에 “분석 전 확인 필요”가 표시되면 분석할 수 없습니다.
페이지 종류별 빈 양식이 빠졌거나 해당 기준 페이지와 크기가 다른 상태입니다. 같은 양식의 PDF인지와 한 부당 페이지 수를 확인한 뒤 다시 불러오세요.

문제가 있는 곳만 다음 장의 편집 도구로 고치면 됩니다.
