자유기입 영역

글, 이름, 날짜, 숫자처럼 사람이 직접 쓰는 답변 칸은 모두 “자유기입”으로 부릅니다.

새 자유기입 영역 만들기

  1. 자유기입 영역 추가를 누릅니다.
  2. 답변이 쓰이는 칸 전체를 드래그합니다. 밑줄만이 아니라 글씨가 들어갈 높이까지 포함합니다.
  3. 보라색 박스와 자유기입 이름이 생겼는지 확인합니다.
  4. 하나 더 만들려면 버튼을 다시 누릅니다. 이름은 자유기입 2, 자유기입 3처럼 자동으로 구분됩니다.
영역을 너무 딱 맞게 그릴 필요는 없습니다.
필기 획이 박스 밖으로 나가지 않을 정도의 작은 여백을 두는 편이 안전합니다.

분석할 때는 스캔 위치 오차를 흡수할 만큼의 작은 안전 여백만 자동으로 더합니다. 화면의 박스 자체는 바뀌지 않으므로 인접 질문까지 포함해 넓게 그리지 마세요.

기존 영역을 자유기입으로 바꾸기

이미 문항으로 만든 영역을 바꾸려면 자유기입 전환을 누르고 목록에서 문항을 선택합니다.

  • 다시 같은 문항을 선택하면 자유기입 지정을 해제할 수 있습니다.
  • 박스를 우클릭해 자유기입으로 지정 또는 자유기입 지정 해제를 선택해도 됩니다.
  • 문항 이름은 선택지 이름 설정 창의 문항 이름에서 바꿀 수 있습니다.

결과에는 어떻게 저장되나요?

결과물저장 내용
엑셀 결과 시트의미 있는 필기가 감지되면 있음, 없으면 빈 칸
자유기입.pdf날짜별 결과 폴더에 필기가 있는 자유기입 페이지를 원본 이미지로 모아 저장
손글씨 내용을 글자로 바꾸는 OCR 기능은 아닙니다.
엑셀에는 작성 여부만 표시되고, 실제 내용은 자유기입 PDF에서 사람이 확인합니다.

자유기입.pdf는 실제로 감지된 내용이 있을 때만 만들어집니다. 모든 칸이 비어 있으면 파일이 생기지 않는 것이 정상입니다.

잘 잡는 요령

  • 질문 문구가 아니라 답변을 쓰는 칸만 포함
  • 긴 문장은 줄 전체를 넉넉히 포함
  • 날짜·전화번호처럼 여러 칸이면 한 답변 단위로 묶어 그리기
  • 두 페이지 설문은 해당 답변이 있는 정확한 페이지에 그리기
  • 선택형 체크박스와 자유기입 영역이 불필요하게 겹치지 않게 하기
